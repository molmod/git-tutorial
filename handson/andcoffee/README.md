# Git(Hub) hands-on tutorial

These instructions are intended for participants of the Git(Hub) & Coffee training.

For the hands-on part, you will use the sandbox repository <https://github.ugent.be/tovrstra/sandbox-coffee-2026>,
where you can experiment and make mistakes without consequences.
This repository is hosted on the GitHub instance of Ghent University
and is only accessible with a UGent account.
You will not make changes in the sandbox directly.
Instead, you will make your own copy of the sandbox, a so-called **fork**, for your edits,
and propose these edits to the sandbox with a **pull request**.

1. Start with the tutorial slides, which are available in the [Releases](https://github.com/molmod/git-tutorial/releases) section of this repository.
   (These will be presented during the live tutorial session.)
1. Then get a basic understanding of GitHub's features by following [`handson_web.md`](./handson_web.md).
1. Finally, dive into the command-line usage of Git with the hands-on tutorial in [`handson_cli.md`](./handson_cli.md).
